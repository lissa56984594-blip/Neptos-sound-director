NEPTUS SOUND DIRECTOR — VERSÃO MODULAR ESTELAR

ESTRUTURA
- index.html: página principal; continua sendo a entrada do site.
- styles.css: identidade visual geral e estilos já existentes.
- cenas.css / cenas.js: visual e funcionamento da área Cenas.
- core.js: armazenamento, navegação, estado compartilhado e serviços comuns.
- biblioteca.js: importação, pesquisa e organização da Biblioteca.
- efeitos.js: importação e reprodução dos efeitos sonoros.
- mixer.js: controles do mixer persistente.
- adelaide.js: preparação da área da Adelaide (a IA ainda não está conectada).
- config.js: backup e restauração dos dados das sessões.

INSTALAÇÃO
1. Faça uma cópia de segurança do repositório atual.
2. Envie TODOS os arquivos desta pasta para a raiz do repositório, mantendo os nomes.
3. Quando o GitHub perguntar, substitua o index.html e styles.css existentes.
4. Não apague a pasta antiga nem o README; eles não são necessários para carregar o site.
5. Aguarde o GitHub Pages atualizar e abra o site. Se aparecer a versão antiga, atualize a página.

IMPORTANTE
- A Biblioteca e os efeitos continuam usando o armazenamento local do navegador (IndexedDB).
- As sessões continuam usando a chave localStorage nsd_sessions; a organização já salva deverá continuar disponível no mesmo navegador.
- Os arquivos de áudio não são enviados ao GitHub; permanecem no armazenamento local do navegador.
- Faça backup dos dados e mantenha os arquivos originais de áudio guardados no celular.
- Esta versão não conecta uma IA real à Adelaide.
